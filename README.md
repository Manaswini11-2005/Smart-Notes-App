# 📝 SmartNotes

A Java-based web application for creating, managing, searching, and organizing personal notes.

## ✨ Features

- 👤 User Registration & Login
- 📝 Create, Edit & Delete Notes
- 🔎 Search Notes
- 🏷️ Add Tags
- 📌 Pin Important Notes
- 💾 MySQL Database Integration

## 🛠️ Tech Stack

**Java | JSP | JDBC | MySQL | HTML | CSS | JavaScript | Apache Tomcat | Eclipse**

## 🚀 How to Run

1. Clone the repository.
2. Import the project into Eclipse.
3. Create the `smartnotes` database using `database/smartnotes.sql`.
4. Configure your MySQL username and password in `DBConnection.java`.
5. Configure Apache Tomcat 9.
6. Run the project on Tomcat.
